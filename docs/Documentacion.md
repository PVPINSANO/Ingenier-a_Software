# SATE-UNIAJC

## Descripción
Sate-Uniajc es una aplicación en la cual se hará un seguimiento a los estudiantes, se tendrá en cuenta datos importantes como las asistencias y las notas de los estudiantes. Esto con el fin de conocer el rendimiento estudiantil y aplicar medidas en caso de un bajo rendimiento académico; tutorías para un mejor desempeño académico 

## Tecnologías

 Java junto con Maven.
 HTML, CSS y JavaScript (se utiliza para la creación de la interfaz web de la aplicacion).
